What OverWatch is

OverWatch is a defensive host-integrity monitor. It watches the things attackers quietly change — files, running processes, and the registry keys that make programs start at boot — and writes every change to a tamper-evident activity log. You can run it on one machine or across a fleet of enrolled devices.

It is read-only with respect to your system. It detects and records; it never hides files or processes and never edits the registry.

The three monitors

Files

Watches specific file paths and reports when they are created, modified, moved, or deleted — handy for config files, host files, startup folders.

Processes

Snapshots running processes every few seconds and reports what started or exited. Read-only — it never kills anything.

Registry autoruns

On Windows, reads the HKLM/HKCU Run and RunOnce keys and flags any new, changed, or removed autostart entry.

Accounts & permissions

  • admin — full read/write: configure monitors, enroll devices, and manage accounts.
  • viewer — read-only: dashboard and activity log.

The first account created is always an admin. After that, admins create accounts from the Users page.

BYOD network integration

Run one OverWatch as the central server. Any other device — laptop, workstation, VM — enrolls as an agent and forwards its events to the server over the network, so the whole fleet shows up in one activity log.

  1. On the server, open Devices and copy the enroll key (or click Enroll device to mint a token directly).
  2. On the device, run the agent:
python -m overwatch agent \
  --server http://SERVER_HOST:{{ config.port }} \
  --enroll-key YOUR_ENROLL_KEY \
  --name "sales-laptop" \
  --watch-process --watch-registry \
  --watch-file "C:\Windows\System32\drivers\etc\hosts"

The agent enrolls once, caches its device token, keeps a local log, and streams events to the server. Revoke any device from the Devices page and its token stops working immediately.

Command line

python -m overwatch run                      # start the server/UI
python -m overwatch create-user NAME --role admin
python -m overwatch agent --server URL --enroll-key KEY --name NAME ...
python -m overwatch status                   # show resolved config

Alerts are opt-in: set OVERWATCH_ALERT_WEBHOOK and warning/critical events are POSTed there.
